# Source lineage

SILGallery is a renamed and reorganized derivative of [alblue/SILInspector](https://github.com/alblue/SILInspector) at commit `6a69cea5126af73dc1964cf92bfa397da3e18752`. The original 2015 Bandlem Limited MIT license and author attribution remain.

Changes include renamed source files and internal declarations, synchronized XIB connections and project references, separated UI/controller/compiler command layers, and reproducible behavior checks. The same deployment-target and Swift-language build settings were applied to the isolated baseline for current-toolchain comparison. This is derivative maintenance, not independent authorship of the upstream application.
